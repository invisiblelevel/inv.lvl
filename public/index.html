Информация о проекте

========================================
  TEXTURE PACK — README
========================================

Этот пак содержит набор PBR-текстур высокого качества.
Все текстуры бесшовные (tileable) и готовы к использованию
в игровых движках и 3D-редакторах.

----------------------------------------
  ЧТО ВНУТРИ ПАКА
----------------------------------------

Каждая текстура включает следующие карты:

  _Albedo      — цвет (Base Color / Diffuse)
  _Normal      — карта нормалей (OpenGL)
  _Height      — карта высот (для parallax / displacement)
  _AO          — ambient occlusion (затенение)
  _Metallic    — металличность
  _Smoothness  — гладкость (для Unity)
  _ORM         — упакованная карта (R=AO, G=Roughness, B=Metallic)

Разрешения: 8K.
Формат: PNG (без потери качества).

----------------------------------------
  ВАЖНО: SMOOTHNESS vs ROUGHNESS
----------------------------------------

В паке лежит карта **_Smoothness** (гладкость).

  Белый = гладкий / блестящий
  Чёрный = шероховатый / матовый

Эта карта подходит для Unity (Built-in, URP, HDRP).

ЕСЛИ ВАМ НУЖНА КАРТА _Roughness (шероховатость):

  В Blender, Substance Painter, Unreal Engine и некоторых
  других движках используется карта Roughness — это
  ПРОТИВОПОЛОЖНОСТЬ Smoothness.

  Чтобы получить Roughness — просто инвертируйте карту
  Smoothness в любом графическом редакторе:

    GIMP:        Цвет → Инвертировать (Ctrl + I)
    Photoshop:   Изображение → Коррекция → Инвертировать
    Krita:       Фильтры → Коррекция → Инвертировать

  Или используйте готовую карту _ORM (см. ниже).

----------------------------------------
  ORM-КАРТА (для Unreal Engine и др.)
----------------------------------------

В паке есть упакованная карта **_ORM.png**, где:
  Красный канал  (R) = Ambient Occlusion
  Зелёный канал  (G) = Roughness
  Синий канал    (B) = Metallic

Если ваш шейдер поддерживает ORM — просто подставьте
эту карту вместо отдельных AO / Roughness / Metallic.

----------------------------------------
  ДЛЯ UNITY
----------------------------------------

Unity (Standard / URP / HDRP) ожидает Metallic и Smoothness
в ОДНОЙ карте:
  Красный канал  (R) = Metallic
  Альфа-канал    (A) = Smoothness

Если у вас нет готовой упакованной карты — можете собрать
её вручную в GIMP / Photoshop, положив _Metallic в красный
канал, а _Smoothness — в альфа-канал.

Не забудьте в настройках текстуры в Unity отключить sRGB
(Color Texture) для всех карт, кроме _Albedo.
